## ✨ Funcionalidades

- Operações básicas: soma, subtração, multiplicação e divisão
- Suporte a teclado físico
- Painel de juros compostos (com aporte mensal)
- Botão de limpar no painel de juros
- Feedback tátil em dispositivos móveis
- Layout responsivo
- Tema escuro personalizado

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)
